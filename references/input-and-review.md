# Input extraction and itinerary review

## Normalize source material

For each item, record its date and local timezone; fixed, estimated, or optional time; origin/destination/venue; public facts and sensitive fields separately; source and confidence; and mismatches needing confirmation.

Never reproduce a QR code or long identifier in conversational summaries. Redact it while confirming that the source was recognized.

## Review priorities

Check fixed-time items first, then transfers, luggage handling, opening hours, meals, and rest. Flag fragile arrival connections, backtracking, carrying luggage through attractions, last-admission conflicts, sparse rural transport, weather-dependent activities, consecutive late/early days, and timezone mismatches.

Keep the venue's local time in the itinerary. When a screenshot uses another timezone, show both values in the confirmation draft and ask the traveler to verify the booking page.

Do not silently delete a requested stop. Offer a recommended route and clearly label optional cuts.

## Links

Use the exact safe URL supplied by the traveler. Resolve shortened map links only when browsing is available. If a social page is blocked, say it could not be fully read and use only its title, visible snippet, screenshot, or user-provided summary.

## Confirmation draft

Include the route and dates, one line per day, fixed reservations, important concerns and unknowns, and the privacy report. Ask for one confirmation covering the itinerary and mode A report. Mode C requires its separate high-risk confirmation.
